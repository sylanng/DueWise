
# BNPL Payment Projection System

A web-based financial management application developed
for CIT 210 – Web Systems and Technologies.

## Project Information

- Institution: West Visayas State University
- Program: BSIT 3A
- Frontend: React.js and Vite
- Backend: Node.js and Express.js
- Database: Firebase Cloud Firestore
- Authentication: Firebase Authentication

## Project Description

The BNPL Payment Projection System helps students
manage Buy Now, Pay Later installment obligations,
allowances, income, and expenses.

It calculates projected available balances, identifies
upcoming installment obligations, and provides
hypothetical purchase simulations.

## Main Features

- Google Authentication
- Installment Management
- Allowance and Income Management
- Expense Management
- Financial Projection
- Reserve Threshold Warnings
- Purchase Simulator
- Gmail API Integration
- Google Calendar Integration

## Project Structure

- client/ - React frontend
- server/ - Express backend
- docs/ - Project documentation

## Currency

All financial amounts use Philippine Peso (PHP).
